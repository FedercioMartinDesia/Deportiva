## 🎨 Sistema de Diseño

### Colores
```
PRIMARY:        #00A86B (Verde Canchas)
PRIMARY_DARK:   #008554
SECONDARY:      #FF6B35 (Naranja Acento)
BACKGROUND:     #F5F5F5
DARK:           #1A1A1A
GRAY:           #757575
WHITE:          #FFFFFF
```

### Tipografía
- **Títulos**: Bold, 24-28px
- **Subtítulos**: SemiBold, 18-20px
- **Cuerpo**: Regular, 14-16px
- **Captions**: Regular, 12-14px

### Espaciado
- **Padding contenedor**: 20px
- **Margin entre secciones**: 20px
- **Border radius cards**: 15px
- **Border radius buttons**: 15px

### Componentes Reutilizables
- **Gradientes**: Primary → Primary Dark
- **Cards**: Fondo blanco, sombra sutil, bordes redondeados
- **Buttons**: Gradiente verde, texto blanco, bordes redondeados
- **Inputs**: Fondo gris claro, iconos a la izquierda
- **Chips**: Pills con borde o relleno según estado

## 📊 Flujo de Usuario

### Usuario Nuevo
```
Login → Registro → Home → Explorar → Detalle Cancha → Reservar
```

### Usuario Existente
```
Login → Home → Perfil/Explorar/Reservas
```

### Búsqueda de Cancha
```
Home/Explorar → Búsqueda → Filtros → Listado → Detalle
```
